# Hypotheses

This is the account's open hypothesis ledger — every testable claim the framework currently holds, at whatever confidence level the evidence actually supports, with a named next experiment to move it forward. It exists because [`docs/evidence-rules.md`](evidence-rules.md) Rule 8 requires replication before optimization: a hypothesis doesn't get promoted into a framework rule just because it sounds right, and it doesn't stay untested forever either — this table is where it's tracked until it's resolved.

Status values follow the same bands used in [`docs/historical-analysis.md`](historical-analysis.md) "Historical Pattern Discovery v1": **Confirmed** (≥80% of the relevant sample), **Likely** (60–79%), **Experimental** (<60% or contradictory), **Unknown** (Meta API cannot determine it).

---

**How to add a new hypothesis:** give it the next sequential `HYP-###` ID, state it as a single testable claim (not a bundle of claims), cite the specific evidence file and section behind its confidence level, and name the experiment (existing or new, in [`docs/experiments-roadmap.md`](experiments-roadmap.md)) that would move it forward. Never mark a hypothesis Confirmed on the strength of it "seeming true" — every row above traces to a specific frequency count in [`docs/historical-analysis.md`](historical-analysis.md), per [`docs/evidence-rules.md`](evidence-rules.md).
