# KPI Thresholds

This file defines Canton's own performance benchmarks, per metric, in one place. It does not invent numbers — every value populated here must already exist in [`docs/historical-analysis.md`](historical-analysis.md), [`docs/experiments.md`](experiments.md), or [`docs/winners.md`](winners.md). Where the evidence is insufficient to state a benchmark, the cell is left empty rather than filled with a guess.

Per [`docs/evidence-rules.md`](evidence-rules.md): populating or changing a value in this file is a strategic change and requires the same citation discipline as any other framework rule.

## Notes

- "Current Historical Benchmark" is drawn only from [`docs/historical-analysis.md`](historical-analysis.md) and [`docs/winners.md`](winners.md) — data that has already been audited and confirmed.
- "Current Experiment Benchmark" is drawn only from active or recently-resolved entries in [`docs/experiments.md`](experiments.md). It stays empty until an experiment produces enough data to be more than a single-data-point placeholder (see [`docs/framework.md`](framework.md) Discovery-stage rules — one sale is not a trend).
- "Target" stays empty across the board in this version. Canton has not yet run the volume of controlled experiments needed to set a forward-looking target with evidence behind it, per [`docs/evidence-rules.md`](evidence-rules.md) Rule 2. Setting a target without that evidence would itself be an opinion, not a framework decision.
- This table should be revisited every time [`docs/experiments.md`](experiments.md) gains a new resolved entry or [`docs/winners.md`](winners.md) gains a new full audit — update the relevant cell and cite the source, then log the change in `CHANGELOG.md`.

**See also:** [`docs/decision-tree.md`](decision-tree.md) for how these metrics are used diagnostically; [`docs/audit-checklist.md`](audit-checklist.md) for where these benchmarks get checked pre-launch; [`docs/evidence-rules.md`](evidence-rules.md) for the citation requirement before any cell in this table changes.
